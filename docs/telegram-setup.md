# Персональный Telegram-помощник

У магазина может быть собственный бот из BotFather или личная ссылка на общий бот FloralAI. Собственный бот закрепляется за одним аккаунтом; повторное подключение обновляет токен того же бота. Переход на другой личный бот пока не предусмотрен.

## Настройка сервера

1. Примените миграцию `personal_telegram_assistant` вместе с предыдущими миграциями.
2. Задайте `NEXT_PUBLIC_APP_URL` с публичным HTTPS-адресом приложения и серверный `SUPABASE_SERVICE_ROLE_KEY`.
3. Добавьте серверный `TELEGRAM_TOKEN_ENCRYPTION_KEY`: 32 случайных байта в виде 64 шестнадцатеричных символов. Например: `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"`. Храните ключ в секретах окружения и сохраняйте между развёртываниями. Он нужен для расшифровки токенов и проверки вебхуков. Ключ нельзя публиковать в клиентском коде.
4. Для свободных AI-консультаций задайте `OPENAI_API_KEY`, `USE_MOCK_AI=false` и при необходимости `OPENAI_MODEL`. Без AI доступны оформление заявок, ответы из профиля, поиск по FAQ и встроенные советы флориста. В интерфейсе показывается фактически доступный режим.
5. Для общего бота дополнительно нужны `TELEGRAM_BOT_TOKEN` и `TELEGRAM_WEBHOOK_SECRET`. Для персональных ботов эти две переменные не требуются.

## Подключение магазина

Владелец сохраняет профиль бизнеса, затем открывает Telegram → «Свой бот магазина». В Telegram создаёт бота через `@BotFather` командой `/newbot` и вставляет токен в поле подключения. Сервер проверяет `getMe`, закрепляет бота за аккаунтом, шифрует токен с AES-256-GCM и регистрирует вебхук. Токен после сохранения не возвращается в браузер. При неудаче регистрации можно повторить подключение. Кнопка «Пауза» останавливает новые ответы, повторное подключение без токена возобновляет работу.

Клиент может открыть обычную ссылку `https://t.me/имя_бота` и написать `/start`; параметр магазина для персонального бота не нужен. В общей версии клиент по-прежнему использует выданную магазином ссылку с `?start=…`. После подключения личного бота старую общую ссылку нужно заменить.

## Знания и поведение

В настройках бизнеса доступны приветствие, язык, стиль общения и публичная база знаний. AI использует весь текст базы. Для режима без AI оформляйте частые вопросы так:

```text
Вопрос: Можно ли заменить цветы в букете?
Ответ: Состав согласовываем до сборки. Укажите здесь реальные условия.

Вопрос: Есть ли открытка?
Ответ: Укажите наличие, стоимость и правила подписи вашего магазина.
```

Общие советы флориста можно отключить. Язык и стиль применяются к AI-консультациям; оформление заявки и встроенные советы пока на русском. AI не получает инструменты изменения заявок, оплаты или уведомления сотрудников. Запрос сотрудника возвращает контакт магазина; уведомление в Telegram владельцу не отправляется.

Вопрос во время оформления сохраняет шаг и черновик. Команда «Продолжить» возвращает к оформлению, а на шаге проверки повторно показывает детали и актуальную сумму. Только явное подтверждение запускает проверенную транзакцию сохранения заявки. AI не создаёт заявки самостоятельно.

Память ограничена последними 10 сообщениями текущего чата и магазина. При `/start`, `/new`, `/cancel` и смене магазина память нового диалога очищается; история уже сохранённых сообщений и заявок в базе остаётся. Чаты, сообщения, заявки и повторные доставки изолированы по ID бота; один клиент может независимо общаться с несколькими магазинами. Повтор вебхука использует сохранённый ответ и не создаёт новую заявку.

Проверки: `npm test`, `npm run lint`, `npm run build`; интеграционные SQL-проверки с откатом — `supabase/tests/telegram_personal.sql`.
